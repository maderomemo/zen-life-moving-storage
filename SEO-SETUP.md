# SEO Setup Guide for Zen Life Moving & Storage

This project includes a clean, semantic foundation for search visibility, but before deployment you must replace all placeholder business information with real details.

## Required before launch

1. Purchase or connect the real business domain.
3. Replace `https://www.zenlifemoving.com` in the canonical URL, sitemap, and robots file with the real production domain.
4. Deploy the website using HTTPS.
5. Verify the website in Google Search Console.
6. Submit the sitemap to Google.
7. Request indexing for the homepage and key service pages.
8. Create and verify the Google Business Profile for the business.
9. Use the exact legal/business name consistently across the website, Google Business Profile, and marketing materials.
10. Add actual service areas and business hours to the website and listing.
11. Verify the website in Bing Webmaster Tools.
12. Submit the sitemap to Bing.
13. Test structured data using Google Rich Results testing tools.
14. Test mobile usability and page speed.
15. Check Core Web Vitals and fix any issues before full promotion.
16. Monitor indexing and search performance over time.
17. Add genuine customer reviews once available.

## Google Business Profile checklist

The business owner should:

1. Create a Google Business Profile.
2. Use the exact legal/business name consistently.
3. Select the most appropriate primary business category.
4. Add the real business information and service areas.
5. Add the website URL.
6. Include a real business phone number, email, and hours.
7. Verify the business listing.
8. Keep the website and Google Business Profile information consistent.

## SEO note

Search engine optimization can improve visibility and indexing, but it does not guarantee a specific ranking, guaranteed placement, or guaranteed visibility in Google, Gemini, Bing, or other search systems.

## Production checklist

- Confirm all website links work correctly after deployment.
- Validate HTML and accessibility before going live.
- Confirm the sitemap contains the live domain and is accessible.
- Confirm the robots file allows crawling.
- Review structured data to ensure it matches the live site.
