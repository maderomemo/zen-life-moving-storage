## Run locally

Open `index.html` directly in a browser. The page includes the styling and interactions without a build step.

## Customize before launch
- Replace `https://www.zenlifemoving.com` in the canonical URL, structured data, sitemap, robots file, and social preview image URL with the production domain.
- Service sections use original local SVG illustrations in the same green, sage, and warm-neutral palette as the hero artwork. The SVGs scale cleanly without relying on external image services. On desktop, the quick-quote card overlays the right side of the branded highway scene and extends close to its lower edge; on smaller screens, it stacks below the image.
- Connect the quote form to a backend or form service before accepting real quote requests.

See [SEO-SETUP.md](./SEO-SETUP.md) for deployment, search indexing, and Google Business Profile guidance.
